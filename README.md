## 📖 Overview

**OpsCom** spans the complete operational lifecycle — from pre-event command planning and resource readiness through live CAD dispatch and incident command, to field MDT, digital patient records, and post-event analysis.

Engineered specifically for environments where software failures have real operational consequences, OpsCom unifies emergency services, event medical providers, fire & rescue, search & rescue, and industrial response teams under a single operational picture.

---

## ⚡ The Operational Lifecycle

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Complete Lifecycle Flow                         │
├─────────────────┬────────────────────┬──────────────────┬──────────────┤
│ 1. Pre-Event    │ 2. Command CAD     │ 3. Field MDT     │ 4. Governance│
│  • Resource Prep│  • Live Incident   │  • Tablet/Mobile │  • Compliance│
│  • Accreditation│  • Unit Dispatch   │  • Clinical ePCR │  • Real-time │
│  • Risk Matrices│  • Multi-Agency Net│  • Offline Sync  │  • Reporting │
└─────────────────┴────────────────────┴──────────────────┴──────────────┘
```

1. **Pre-Event Command & Readiness:** Credentialing, staff briefing packs, resource allocation rosters, and operational orders.
2. **CAD / Command & Control:** Live situation map, automated resource dispatch, mutual aid coordination, and major incident protocols.
3. **MDT / Field Operations:** Real-time unit status updates, electronic patient care records (ePCR), and GPS tracking with offline resilience.
4. **Clinical Governance & Oversight:** Automated compliance auditing, clinical director oversight, drug register logs, and incident reporting.

## 🎯 Operational Solutions

| Sector | Operational Focus | Key Capabilities |
| :--- | :--- | :--- |
| 🎪 **Event Medical** | Festivals, Arenas & Stadiums | Rapid triage, crowd density monitoring, medical tent bed management, and multi-agency liaison. |
| 🚑 **Ambulance Services** | Private & Municipal EMS | Fast dispatch triage, vehicle telematics, hospital handoff notifications, and NEMSIS/NHS compliance. |
| 🚒 **Fire & Rescue** | Incident Scene Command | Water supply mapping, appliance status tracking, sectorization, and crew breathing apparatus (BA) tallies. |

| 🏭 **Industrial Response** | High-Hazard Sites | Geofenced hazmat alerts, lone worker monitoring, automated muster point headcounts, and emergency shutdown integration. |

## 🏛️ Architecture & Resilience

- **Dark Mode Command Aesthetic:** Engineered for low-light command centres and night field operations with high-contrast accessibility.
- **Responsive Semantic UI:** Built with modern Tailwind CSS and lightweight Lucide vector iconography.
- **Edge Deployment:** Zero-dependency runtime compatible with static CDNs and local containerized deployments.

## 🚀 Quick Start

### Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arabiabdou453-cpu/opscom.git
   cd opscom
   ```

2. **Start the local server:**
   ```bash
   npm start
   ```
   *Or run directly:*
   ```bash
   node server.js
   ```

3. **Open in browser:**
   ```
   http://localhost:3000/
   ```
